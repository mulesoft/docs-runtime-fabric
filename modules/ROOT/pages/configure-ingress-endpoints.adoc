= Configuring Ingress Endpoints for Mule App Deployment

To configure ingress endpoints for a Mule app deployment, complete these tasks:

. Create an ingress resource template and apply it in the cluster.
. Configure ingress for a Mule app.

== Before You Begin

Before configuring ingress in Runtime Fabric, set up an ingress controller. For a list of ingress controllers, refer to the https://kubernetes.io/docs/concepts/services-networking/ingress-controllers/[Kubernetes documentation].
