= Upgrading Runtime Fabric on OpenShift

Red Hat OpenShift console allows you to run upgrades automatically (default) or manually. You can change this setting in the *Subscription* tab in the Runtime Fabric Operator. 

[Note]
Starting with Runtime Fabric agent version 2.4.0, for any new Mule app deployment, you must use a Mule runtime image built on Aug 8, 2023, or later.

== Before You Upgrade

Before you upgrade Runtime Fabric on Red Hat OpenShift, make sure that:

* Your cluster runs a Kubernetes version that the target Runtime Fabric version supports. For the supported Kubernetes versions for each release, see xref:release-notes::runtime-fabric/runtime-fabric-release-notes-3.x.x.adoc[Runtime Fabric Release Notes].
+
To check the Kubernetes version of your cluster, run this command in your terminal:
+
[source,copy]
----
oc version
----
+
If OperatorHub doesn't offer a newer Runtime Fabric operator, your cluster's Kubernetes version might be lower than the minimum version that the newer operator supports. Upgrade your OpenShift cluster, and then upgrade Runtime Fabric.
* If you use a local registry, you have synchronized the images for the target Runtime Fabric version. If an image is missing, the upgrade stalls. See xref:configure-local-registry.adoc#synch-rtf[Synchronize Runtime Fabric Core Software Images].
* You don't edit component versions in the Runtime Fabric agent ConfigMap or in `app-config` manually. The operator manages these values and overwrites manual changes.

== Upgrade Runtime Fabric on Red Hat OpenShift

To upgrade Runtime Fabric on Red Hat OpenShift, use the Runtime Fabric operator in the Red Hat OpenShift console.

. In the Red Hat OpenShift console, navigate to *Operators > Installed Operators*.
. Select the Runtime Fabric operator.
. Click *Upgrade*.

== Upgrade to an Intermediate Runtime Fabric on Red Hat OpenShift

To upgrade to an intermediate Runtime Fabric OpenShift operator, you need to uninstall the previous version and install the intermediate version:

. From the OpenShift console, uninstall the Runtime Fabric operator, without deleting or uninstalling Runtime Fabric instances or clusters.
. On the OpenShift console find the Runtime Fabric operator in the Operator Hub and install the desired version.

This automatically triggers the upgrade of the existing Runtime Fabric instances.

== Verify the Upgrade

To verify the upgrade, run these commands in your terminal:

. Check that the operator version is the target version and that its phase is `Succeeded`:
+
[source,copy]
----
oc get csv -n <rtf_namespace>
----
. Check that the Runtime Fabric pods are running and ready:
+
[source,copy]
----
oc get pods -n <rtf_namespace>
----
