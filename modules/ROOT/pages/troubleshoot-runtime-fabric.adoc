= Troubleshooting Runtime Fabric

Use this page to resolve Runtime Fabric issues. You can also use the xref:troubleshoot-rtf-rtfctl.adoc[RTFCTL tool] to troubleshoot further.

[[troubleshoot-403-forbidden-image-pull]]
== Troubleshoot a 403 Forbidden Image Pull

A Helm install fails with `403 Forbidden` when the agent pulls `mulesoft/rtf-daemon`. The Helm chart uses `mulesoft` when `repositoryNamespace` is absent. Runtime Manager sets the correct namespace for your control plane in `values.yaml`. An install that skips this file pulls `mulesoft/rtf-daemon`, and the registry returns `403 Forbidden` when your control plane uses a different namespace.

To correct the image pull:

. In Runtime Manager, open the Runtime Fabric.
. Select *Helm*.
. Under *Download and configure the values.yaml file*, click *Download values.yaml*.
. Use the `repositoryNamespace` value from the downloaded file. When the file omits this key, the chart default `mulesoft` applies.
. Rerun this command:
+
[source,copy]
----
helm install runtime-fabric rtf/rtf-agent --version <VERSION_FROM_UI> -f values.yaml -n <namespace>
----
