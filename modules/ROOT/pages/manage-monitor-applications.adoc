= Monitoring Applications Deployed to Runtime Fabric

Anypoint Runtime Fabric provides several observability options for Mule apps and API gateways. Use this table to determine which option suits your needs:

[cols="1,2,1,1"]
|===
|Option |Description |Subscription |Configuration

|Anypoint Monitoring — metrics
|CPU, memory, and throughput data for app replicas
|All plans
|Enabled by default. See xref:use-anypoint-monitoring.adoc#enable-anypoint-monitoring[Enable Anypoint Monitoring].

|Anypoint Monitoring — logs
|Application log search and retrieval in Anypoint Monitoring
|https://www.mulesoft.com/anypoint-pricing[Anypoint Platform Integration Advanced]
|See xref:use-anypoint-monitoring.adoc#logs[Enable and Configure Log Forwarding] and xref:deploy-to-runtime-fabric.adoc#configure-logging-and-log-levels[Configure Logging and Log Levels].

|Anypoint Monitoring — traces
|Full transaction-path visibility using OpenTelemetry
|https://www.mulesoft.com/anypoint-pricing[Anypoint Platform Integration Advanced]
|See xref:use-anypoint-monitoring.adoc#enable-trace-data[Enable Trace Data Collection].

|External telemetry (Log4j)
|Route logs to an external logging system using a Log4j appender
|All plans
|See xref:use-log4j-appender.adoc[Use Log4j Appender].

|===
